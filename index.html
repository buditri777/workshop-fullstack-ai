08 · EXAMPLE

The Magic Prompt 🪄

Persona: Kamu senior fullstack developer expert Next.js 14 + Supabase + TypeScript.

Project: Task Manager Web App
Stack:
- Next.js 14 (App Router, TypeScript, Tailwind CSS)
- Supabase (Auth + Postgres + RLS)
- Deploy ke Vercel

Features:
1. Auth: register, login, logout via email/password
2. Dashboard: list tasks user yang lagi login
3. CRUD task: title, description, due_date, priority (high/med/low),
   status (todo/in_progress/done), category
4. Filter by status & priority
5. Dark mode toggle (persisted di localStorage)
6. Responsive: mobile + desktop

Database Schema:
- users (auth.users dari Supabase)
- tasks (id, user_id FK, title, description, due_date, priority,
         status, category, created_at)
- RLS: user cuma bisa CRUD task miliknya sendiri

Output:
1. Struktur folder lengkap
2. SQL schema + RLS policies
3. Kode tiap file (app/, components/, lib/)
4. Instruksi setup .env, install deps, run dev
5. Checklist test manual

Constraints: TypeScript strict, no any,
gunakan Server Components kalau memungkinkan, error handling proper.

10 · SUPABASE

Setup Database dengan AI

💬 Prompt ke Codex
Generate Supabase SQL untuk tabel tasks dengan kolom:
- id (uuid, primary key, default uuid_generate_v4())
- user_id (uuid, FK ke auth.users)
- title (text, required)
- description (text)
- due_date (timestamp)
- priority (enum: high, medium, low)
- status (enum: todo, in_progress, done)
- category (text)
- created_at, updated_at (timestamp)

Plus RLS policies: user cuma bisa SELECT/INSERT/UPDATE/DELETE
record dengan user_id = auth.uid()
🤖 Output AI
-- Create enum types
CREATE TYPE task_priority AS ENUM ('high', 'medium', 'low');
CREATE TYPE task_status AS ENUM ('todo', 'in_progress', 'done');

-- Tasks table
CREATE TABLE tasks (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE,
  title text NOT NULL,
  description text,
  due_date timestamptz,
  priority task_priority DEFAULT 'medium',
  status task_status DEFAULT 'todo',
  category text,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);

-- Enable RLS
ALTER TABLE tasks ENABLE ROW LEVEL SECURITY;

-- Policy: users only see own tasks
CREATE POLICY "own_tasks" ON tasks
  FOR ALL USING (auth.uid() = user_id);
11 · AUTH

Auth Flow dengan Supabase

①

User Register

Form email + password → supabase.auth.signUp()

Supabase kirim verification email otomatis

→
②

User Login

supabase.auth.signInWithPassword()

Return session + JWT token, simpan di cookie

→
③

Protected Pages

Middleware check session sebelum render

Kalau gak login → redirect ke /login

→
④

RLS Auto-filter

Query SELECT * FROM tasks

Postgres otomatis filter by auth.uid()

🔐 Magic-nya: kamu gak perlu nulis "WHERE user_id = ..." di setiap query. RLS handle di database level. Aman!

14 · SECURITY

Environment Variables & Secrets

Variable
Public?
Storage
Use
NEXT_PUBLIC_SUPABASE_URL
✅ Yes
.env.local + Vercel
Client-side query
NEXT_PUBLIC_SUPABASE_ANON_KEY
✅ Yes
.env.local + Vercel
Client-side auth (RLS protect)
SUPABASE_SERVICE_ROLE_KEY
❌ NEVER
Server-only env
Admin tasks (skip RLS)
OPENAI_API_KEY
❌ NEVER
Server-only env
Server API calls only

⚠️ Yang Sering Bocor

  • ❌ Commit .env.local ke GitHub → token leaked dalam menit
  • ❌ Pakai prefix NEXT_PUBLIC_ untuk service role key
  • ❌ Hardcode API key di kode

✅ Selalu: .gitignore .env* · gunakan Vercel Env Variables · rotate kalau bocor

16 · TIPS

Tips Biar Apl-mu Stand Out

01

📝 Bikin Spec Dulu

Jangan langsung suruh AI ngoding. Bikin SPEC.md dengan AI dulu — schema, user flow, fitur. Ini "blueprint"-nya.

02

🧪 Test di Local Dulu

Sebelum push, jalankan npm run build. Kalau build error di local, pasti error di Vercel juga.

03

📦 Deps Minimal

Setiap package = 1 dependency hell. Jangan install lib yang gak perlu. Tailwind + Supabase = sudah cukup.

04

🎯 Loading & Error States

App professional punya: loading spinner, empty state, error boundary. AI bisa generate semuanya — mintain.

05

📱 Mobile-First

Test di hp! Mayoritas user akses dari mobile. Tailwind sm: md: lg: wajib hukumnya.

06

🔍 SEO & Meta

Title, description, OG image. app/layout.tsx → metadata. Kalau di-share di WhatsApp, kelihatan profesional.

17 · MISTAKES

Kesalahan yang Sering Terjadi ❌

🤖

Trust AI 100%

AI bisa hallucinate. Selalu verify: jalankan kode, cek hasil, baca log.

📋

Prompt Cuma "Bikin App Tasks"

Hasilnya generic. Spec detail = output detail. Garbage in → garbage out.

🔑

Commit .env ke GitHub

Token bocor → orang bisa akses database kamu. Cek .gitignore.

🚫

Skip RLS di Supabase

Tanpa RLS, user A bisa baca data user B. Wajib enable RLS.

🐛

Push tanpa Test

"Di local jalan kok" — sampai prod down. Test edge case: empty state, error.

🎨

UI Default Tanpa Polish

Bare Tailwind = obvious AI-generated. Kasih sentuhan personal: warna brand, illustration, custom font.
